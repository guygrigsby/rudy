# Serve Wave Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `rudy serve` runs the same server on a unix socket; `rudy`, `rudy -p` and `rudy sessions resume|fork` attach to it when it answers and embed otherwise; a turn outlives its terminal; a reattach replays and follows; permission questions reach every attached asker.

**Architecture:** One new transport in `internal/protocol` (a unix listener with a peer uid check and a dialer with a probe timeout), one new command in `internal/cli` (`serve`), one dial helper shared by every client command, and three server rules (questions to every asker, `no_asker` when the last asker leaves, `turn.state` plus the standing question on attach). The server suite runs once per transport.

**Tech Stack:** Go 1.26, `golang.org/x/sys/unix` (peer credentials; already an indirect dependency, becomes direct), `net` unix sockets, the existing `protocol.NewStreamConn`, cobra, xpty for the real path.

**Spec:** `docs/specs/2026-09-07-rudy-design.md` (Client, CLI, Durability), `docs/adr/0014-the-serve-wave.md`, `docs/specs/rudy-contracts.md` pass 4 (transports, caller classes, `session.resume`, `session.answer`, `turn.state`, `permission.requested`, the error taxonomy), `docs/specs/rudy-domain-model.md` (Turn invariants and states).

## Global Constraints

- The kernel has no private path to its own features; the socket serves the same `Server.Serve` the in-memory transport does, as caller class client, never plugin.
- `config.toml` is read, never written. No new config fields; `--socket` and `--embed` are flags.
- Socket directory `0700`, socket `0600`, peer uid equals the server's uid or the connection is closed before a byte is read.
- The client dial order: explicit `--socket` or fail; else the default socket with a 50ms probe; else embed. `--embed` skips the probe.
- Sessions close at rest when unattached, as today. No idle timer. No timers anywhere in this wave.
- A permission question goes to every attached asker; the first answer decides; a later answer is `conflict`; the last asker detaching while a question stands is a `no_asker` denial.
- Every server test runs over both transports (`RUDY_TEST_TRANSPORT=socket`); `make test` runs the server package twice.
- Vendor types stay under the codecs and provider plugins (`make vendor-types`).
- `for range n`, never a three-clause count loop. Commits: terse, verb-first, area prefix (`protocol:`, `server:`, `cli:`, `config:`, `docs:`), no em or en dashes, no Oxford commas, no attribution trailers.
- Gate before every commit: `gofmt -l .` empty, `go vet ./...`, `golangci-lint run ./...` 0 issues, `go test -race ./...`, `make check`.

### Task 2: The unix socket transport

**Files:**
- Create: `internal/protocol/unixsock.go`, `internal/protocol/unixsock_darwin.go`, `internal/protocol/unixsock_linux.go`, `internal/protocol/unixsock_test.go`

**Interfaces:**
- Consumes: `protocol.NewStreamConn(r io.Reader, w io.Writer, closer io.Closer) Conn`.
- Produces:
  - `func ListenUnix(path string) (net.Listener, error)`: `MkdirAll(dir, 0700)`, `Chmod(dir, 0700)`; if a socket file exists, dial it with a 50ms timeout: answering means `ErrSocketBusy` (a server is serving it), refusing means stale, remove it; listen; `Chmod(path, 0600)`.
  - `var ErrSocketBusy = errors.New("protocol: a server is already serving this socket")`.
  - `func AcceptPeer(l net.Listener) (Conn, error)`: `Accept`, then `PeerUID(conn)`; a uid other than `os.Getuid()` closes the connection and returns `ErrPeerRefused` (the caller logs and keeps accepting); otherwise `NewStreamConn(c, c, c)`.
  - `var ErrPeerRefused = errors.New("protocol: peer uid is not the server's")`.
  - `func PeerUID(c *net.UnixConn) (int, error)`: darwin `unix.GetsockoptXucred(fd, unix.SOL_LOCAL, unix.LOCAL_PEERCRED)` and `.Uid`; linux `unix.GetsockoptUcred(fd, unix.SOL_SOCKET, unix.SO_PEERCRED)` and `.Uid`. Get the fd through `c.SyscallConn().Control`.
  - `func DialUnix(ctx context.Context, path string, timeout time.Duration) (Conn, error)`: `net.Dialer{Timeout: timeout}.DialContext(ctx, "unix", path)`; wraps `ENOENT` and `ECONNREFUSED` as `ErrNoServer` so a probe can tell "nobody there" from a real failure.
  - `var ErrNoServer = errors.New("protocol: no server on the socket")`.

The refusal branch is unit-tested by injecting the uid check: make `AcceptPeer` call a package variable `peerUID = PeerUID` and set it to return `os.Getuid()+1` in the test.

### Task 3: Questions to every asker, no_asker when the last one leaves, the state on attach

**Files:**
- Modify: `internal/server/session_live.go` (`firstAsker` becomes `askers()`, `liveAsker.Ask`, `subscribeLocked`), `internal/server/server.go` (`handleAnswer`, `detach`, `installAndAttach`, `attachIfLive`), `internal/server/server_test.go`
- Test: `internal/server/asker_test.go`

**Interfaces:**
- Consumes: `liveSession.pending map[string]chan turn.Answer`, `conn.asker`, `conn.notify`, `protocol.NotifyPermissionRequested`, `protocol.NotifyTurnState`, `turn.Answer`, `errNoAsker`.
- Produces:
  - `liveSession.askers() []*conn`: every subscriber with `asker && plugin == ""`, then the parent's when none (the child binding stays).
  - `liveSession.standing map[string]protocol.PermissionRequested`: the questions currently asked, keyed by tool_use id, set when `Ask` sends and cleared when answered or denied.
  - `Ask` sends the question to every asker; with none it returns `errNoAsker` as today.
  - `handleAnswer`: the first answer wins; a `tool_use_id` in `answered` (a set kept until the turn rests) is `conflict`; unknown is `not_found`.
  - `detach`: after removing the connection, if `askers()` is empty and `standing` is not, every standing question is answered `turn.Answer{Decision: deny, Reason: "no asker attached"}` with `decidedBy no_asker` (the Gate's existing `no_asker` path; find how `errNoAsker` becomes the `permission_decision` today and reuse that function rather than a second one).
  - `subscribeLocked` returns, beside the entries and info, the current `turn.state` payload when a turn is active and the standing questions when `cn.asker`; `installAndAttach` and `attachIfLive` send them after `replay` and before returning.
