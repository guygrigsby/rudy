# rudy plugins wave Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every extension point the design names arrives through the one plugin interface: kernel-fired hooks, compaction behind `session.compact` and `/compact`, subagents as child sessions through an `agent` tool, skills, memory through memory-go, the `anthropic_messages` codec, the clinepass dialect, MCP servers under one plugin, spawned plugins over stdio with `wire: custom` providers, and the `rudy mcp`, `rudy plugin` and `rudy skills` commands.

**Architecture:** The kernel gains three things and nothing else: hook firing (turn loop and server), a Compactor domain service, and child sessions (`session.open` with `parent`). Everything else is a plugin registered through `plugin.Host`, which grows `RegisterHook`, `SetStatus`, `SetWidget`, `Note` and `Connect`. A linked plugin reaches the server through `Host.Connect`, an in-memory protocol client authenticated as caller class plugin; a spawned plugin reaches it over stdio through the same requests, so the `agent` tool, the memory plugin and a third-party subprocess all use one path. The memory plugin imports memory-go and the memory project learns rudy's `entries.jsonl` as a third transcript format, proven by its golden gate.

**Tech Stack:** Go 1.26, `github.com/anthropics/anthropic-sdk-go` 1.71.0 (exact), `github.com/modelcontextprotocol/go-sdk` 1.7.0 (exact), `github.com/aeryx-ai/memory/memory-go` through a `replace` to `../memory/memory-go`, `go.yaml.in/yaml/v3` 3.0.4 (already in the module graph) for frontmatter, `github.com/pelletier/go-toml/v2` for `mcp.toml`, `plugin.toml` and `plugins.lock.toml`, `git` on PATH for `rudy plugin install`. Node 22 in the memory repository for its golden generator.

**Spec:** `docs/specs/2026-09-07-rudy-design.md` (Plugins, Memory, CLI, Sequencing item 3), `docs/adr/0012-the-plugins-wave.md` (the eight decisions this plan implements), `docs/specs/rudy-contracts.md` pass 3 and `docs/specs/rudy-domain-model.md`, normative on names, fields, enum values and JSON shapes. Read the contracts' `Published events, the hook points` table before Task 2, `Requests, client to server` (the `plugin.*` rows) and `Requests, server to plugin` before Task 12, the `mcp.toml` and `plugins.lock.toml` sections before Tasks 11 and 13. In the memory repository, `~/projects/memory/docs/specs/2026-08-28-memory-design.md` and `src/transcript.mjs` are the authority for Task 9.

## Global Constraints

- Module `github.com/guygrigsby/rudy`, `go 1.26`. `CGO_ENABLED=0` builds. Dependencies added by this plan are pinned exactly: `github.com/anthropics/anthropic-sdk-go v1.71.0`, `github.com/modelcontextprotocol/go-sdk v1.7.0`. memory-go is `require github.com/aeryx-ai/memory/memory-go v0.0.0` with `replace github.com/aeryx-ai/memory/memory-go => ../memory/memory-go`; the memory repository has no remote yet, so CI for rudy checks out both repositories side by side (Task 15 edits the workflow).
- `for range n`, never a three-clause count loop.
- The kernel has no private path to its own features. Every built-in in this plan registers through `plugin.Host`, and a built-in that needs the server (the `agent` tool, the memory plugin's notes) goes through `Host.Connect` or `Host.Note`, never through a `*server.Server`.
- No vendor or wire types outside the codec packages and the adapters that own them: `internal/provider/openaichat`, `internal/provider/anthropicmsgs` and `internal/plugins/mcp`. After this plan `grep -rl 'anthropic-sdk-go' internal` lists only files under `internal/provider/anthropicmsgs`, `grep -rl 'modelcontextprotocol' internal` only files under `internal/plugins/mcp`, and `grep -rl 'memory-go' internal` only files under `internal/plugins/memory`.
- Tool inputs and thinking signatures are `json.RawMessage` or `string` carried byte-exact. A hook that returns `modify` replaces the input with the bytes the hook returned, verbatim. An MCP tool call passes `call.Input` to the go-sdk as `json.RawMessage`, never through a map.
- An unsafe tool runs only after its `permission_decision` allow entry is appended and fsynced. No asker means deny. A child session's asker is its parent session's asker (Task 5); a hook `allow` or `deny` is recorded with `decided_by: hook` and still goes through `Session.Append` before the tool runs.
- `config.toml` is read, never written. This plan writes exactly two new files under the XDG roots, `$XDG_CONFIG_HOME/rudy/mcp.toml` (and `<workspace>/.rudy/mcp.toml`) by `rudy mcp` and `$XDG_DATA_HOME/rudy/plugins.lock.toml` by `rudy plugin`, plus the checkouts under `$XDG_DATA_HOME/rudy/plugins/<name>/` and skill copies under `~/.agents/skills/<name>/` by `rudy skills migrate`. Each is written whole through a temp file and rename.
- The hook set is the closed nine of the contracts. A handler gets `hook_timeout_ms` (default 5000); a timeout, error or panic skips that handler with a notice naming the plugin and the point, and the turn continues.
- Errors are handled where recovery is possible. A plugin that fails to load is a failed status and a notice. A spawned plugin that dies is marked failed with its stderr tail in a notice, its registrations are withdrawn, and the session continues. An MCP server that fails to connect is a notice and the other servers' tools stand. A fold that fails is a `note` entry with role `warn`, never a turn failure.
- Every provider request still carries `User-Agent: rudy/<version> (<GOOS>/<GOARCH>)` and `X-Rudy-Session: <session ulid>`; the anthropic codec sends through `httpx.Client` for that reason and disables the SDK's own retries.
- Tests: `go test -race ./...` green at every commit. No network in tests; recorded fixtures under `testdata/` are the only provider bytes tests see. Tests never touch `~/.agents/memory`, `~/.config/rudy` or `~/.local/share/rudy`: every test that needs a home sets `XDG_*` to `t.TempDir()` through `BuildOptions.Env` and `Home`.
- Commits: terse, verb-first, area prefix (`plugin:`, `turn:`, `server:`, `session:`, `protocol:`, `provider:`, `config:`, `cli:`, `tools:`, `docs:`, `repo:`; in the memory repository `core:`, `go:`, `golden:`), no em or en dashes, no Oxford commas, no attribution trailers, one `git commit -m` line.
- Work is tracked in beads under the epic Task 0 creates. Claim the task's issue before starting, close it in the task's final commit step.

```go
// ExpandHome replaces a leading "~/" with home. Anything else is returned as is, so a

func ExpandHome(p, home string) string {
	if p == "~" {
		return home
	}
	if strings.HasPrefix(p, "~/") {
		return filepath.Join(home, p[2:])
	}
	return p
}
```

```go
func (p HookPoint) Valid() bool {

		HookAfterTool, HookBeforeCompaction, HookTurnCompleted, HookSessionClosed:

func ResultFor(point HookPoint) any {
	switch point {
	case HookSessionOpened:
		return &SessionOpenedResult{}
	case HookBeforeTurn:
		return &BeforeTurnResult{}
	case HookBeforeRequest:
		return &BeforeRequestResult{}
	case HookBeforeTool:
		return &BeforeToolResult{}
	case HookAfterTool:
		return &AfterToolResult{}
	case HookBeforeCompaction:
		return &BeforeCompactionResult{}
	}
	return nil

type HookRunner struct {
	reg     *Registry
	timeout time.Duration
	notice  func(string)
}

func NewHookRunner(reg *Registry, timeout time.Duration, notice func(string)) *HookRunner {
	if notice == nil {
		notice = func(string) {}
	}
	return &HookRunner{reg: reg, timeout: timeout, notice: notice}
}

// Fire runs the handlers for call.Point in registry order. Each gets its own deadline; a
// handler that errors, panics or times out is skipped with a notice and never stops the
// others. Results that are nil, or nil pointers, are dropped.
func (h *HookRunner) Fire(ctx context.Context, call HookCall) []any {
	var out []any
	for _, oh := range h.reg.Hooks(call.Point) {
		res, err := h.one(ctx, oh, call)
		if err != nil {
			h.notice(fmt.Sprintf("hook %s: %s: %v", call.Point, oh.Owner, err))
			continue
		}
		if res != nil && !isNilPointer(res) {
			out = append(out, res)
		}
	}
	return out
}

func (h *HookRunner) one(ctx context.Context, oh OwnedHook, call HookCall) (res any, err error) {
	hctx, cancel := context.WithTimeout(ctx, h.timeout)
	defer cancel()
	done := make(chan struct{})
	go func() {
		defer close(done)
		defer func() {
			if p := recover(); p != nil {
				err = fmt.Errorf("panic: %v", p)
			}
		}()
		res, err = oh.Handle(hctx, call)
	}()
	select {
	case <-done:
		return res, err
	case <-hctx.Done():
		// The handler goroutine keeps running until it notices the context; its late
		// result is discarded. Reading res or err here would race, so report the timeout
		// alone.
		return nil, fmt.Errorf("timed out after %s", h.timeout)
	}
}
```

```go
// was running when it happened, are kept. Without a compaction it is every entry.
func (s *Session) requestContextLocked() []Entry {
	all := s.entriesLocked()
	for i, e := range slices.Backward(all) {
		c, ok := e.Payload.(Compaction)
		if !ok {
			continue
		}
		out := []Entry{e}
		for _, x := range all {
			if x.ID.Compare(c.LastEntryID) > 0 && x.ID != e.ID {
				out = append(out, x)
			}
		}
		_ = i
		return out
	}
	return all
}
```

```go
func (p *agentPlugin) invoke(ctx context.Context, call tool.Call) (tool.Result, error) {
	var a struct{ Agent, Prompt string }
	if err := json.Unmarshal(call.Input, &a); err != nil || a.Agent == "" || strings.TrimSpace(a.Prompt) == "" {
		return fsroot.Fail("agent: input needs agent and prompt"), nil

	client, err := p.host.Connect(ctx)

		return fsroot.Fail("agent: %v", err), nil

	err = client.Call(ctx, protocol.MethodSessionOpen, protocol.SessionOpenParams{
		Cwd: call.Workspace.Root, Agent: a.Agent,
		Parent: &protocol.ParentRef{SessionID: call.SessionID.String(), ToolUseID: call.ID},
	}, &info)
	if err != nil {
		return fsroot.Fail("agent: open: %v", err), nil
	}
```

```go
type Options struct {
	Name    string
	BaseURL string            // e.g. https://api.anthropic.com; the SDK appends /v1/messages
	APIKey  string            // "" sends no x-api-key
	Headers map[string]string
	HTTP    *httpx.Client
}

type Client struct{ opts Options }

func New(o Options) *Client { return &Client{opts: strings.TrimRight-normalized o} }
func (c *Client) Name() string { return c.opts.Name }

// sdk builds a per-request SDK client whose transport is httpx.Do with the session id, so
// every request carries rudy's headers and retry policy and the SDK retries nothing itself.
func (c *Client) sdk(sessionID ulid.ULID, extra map[string]string) anthropic.Client {
	opts := []option.RequestOption{
		option.WithBaseURL(c.opts.BaseURL),
		option.WithMaxRetries(0),
		option.WithHTTPClient(&doer{c: c.opts.HTTP, sid: sessionID}),
	}
	if c.opts.APIKey != "" {
		opts = append(opts, option.WithAPIKey(c.opts.APIKey))
	}
	for k, v := range c.opts.Headers {
		opts = append(opts, option.WithHeader(k, v))
	}
	for k, v := range extra {
		opts = append(opts, option.WithHeader(k, v))
	}
	return anthropic.NewClient(opts...)
}

type doer struct {
	c   *httpx.Client
	sid ulid.ULID
}

func (d *doer) Do(req *http.Request) (*http.Response, error) { return d.c.Do(req.Context(), req, d.sid) }

func (c *Client) Complete(ctx context.Context, req provider.Request, emit func(provider.Part) error) error {
	params, err := buildParams(req)
	if err != nil {
		return err
	}
	stream := c.sdk(req.SessionID, req.Headers).Messages.NewStreaming(ctx, params)
	st := newStreamState(emit)
	for stream.Next() {
		if err := st.event(stream.Current()); err != nil {
			return err
		}
	}
	if err := stream.Err(); err != nil {
		return classify(ctx, err)
	}
	return st.finish()
}
```

`classify` maps `*anthropic.Error` (status, the body's `error.message`) to `*provider.Error{Class: ErrProvider, Status, Message, Body, Attempts: attemptsFrom(err)}`, `*httpx.Error` to `ErrTransport` with its Attempts, `ctx.Err()` to itself, anything else to `ErrTransport` Attempts 1. Attempts for an SDK error come from the response the SDK error carries (`apierror.Error.Response`) through `httpx.AttemptsOf`.

```go
func buildParams(req provider.Request) (anthropic.MessageNewParams, error) {
	p := anthropic.MessageNewParams{Model: anthropic.Model(req.Model.Model), MaxTokens: int64(req.MaxTokens)}
	if req.System != "" {
		p.System = []anthropic.TextBlockParam{{Text: req.System}}
	}
	if budget := thinkingBudget(req.Thinking); budget > 0 {
		p.Thinking = anthropic.ThinkingConfigParamOfEnabled(budget)
		if p.MaxTokens <= budget {
			p.MaxTokens = budget + 1024
		}
	}
	for _, t := range req.Tools {
		p.Tools = append(p.Tools, param.Override[anthropic.ToolUnionParam](rawTool{Name: t.Name, Description: t.Description, InputSchema: t.Schema}))
	}
	for i, m := range req.Messages {
		mp, err := buildMessage(m)
		if err != nil {
			return p, fmt.Errorf("anthropicmsgs: message %d: %w", i, err)
		}
		p.Messages = append(p.Messages, mp)
	}
	return p, nil
}

	Description string          `json:"description,omitempty"`
	InputSchema json.RawMessage `json:"input_schema"`

	case session.ThinkingLow:
		return 1024
	case session.ThinkingMedium:
		return 4096
	case session.ThinkingHigh:
		return 16384
	}
	return 0
}
```

```go
type memPlugin struct {
	cfg         config.MemoryConfig
	sessionsDir string
	version     string
	summarize   func(ctx context.Context, prompt string) (string, error)
	host        plugin.Host
	b           *memory.Bundle
	mu          sync.Mutex
	projects    map[string]string // session id -> project id, from session_opened
	models      map[string]session.ModelRef
}

func (p *memPlugin) Name() string { return "memory" }

func (p *memPlugin) Init(ctx context.Context, h plugin.Host) error {
	if !p.cfg.Enabled {
		return nil
	}
	p.host = h
	p.b = memory.New(memory.ResolveRoot(p.cfg.Dir, os.Getenv))
	if !p.b.Exists() {
		h.Notice(fmt.Sprintf("memory: no bundle at %s; run memory init", p.b.Root))
		return nil
	}
	for _, hh := range []plugin.HookHandler{
		{Point: plugin.HookSessionOpened, Handle: p.onOpened},
		{Point: plugin.HookTurnCompleted, Handle: p.onTurnCompleted},
		{Point: plugin.HookBeforeCompaction, Handle: p.onBeforeCompaction},
		{Point: plugin.HookSessionClosed, Handle: p.onClosed},
	} {
		if err := h.RegisterHook(hh); err != nil {
			return err
		}
	}
	return errors.Join(p.registerTools(h), h.RegisterCommand(p.command()))
}
```

```go
func sessionName(id string) string { return "rudy:session/" + id }

var actorClean = regexp.MustCompile(`[^A-Za-z0-9._:-]`)

// actorFor is rudy/<model id> with characters outside the OKF actor alphabet replaced.
func actorFor(m session.ModelRef) string { return "rudy/" + actorClean.ReplaceAllString(m.Model, "-") }

type sdkSummarizer struct {
	ctx context.Context
	run func(ctx context.Context, prompt string) (string, error)
}

func (s sdkSummarizer) Summarize(prompt string) (string, error) { return s.run(s.ctx, prompt) }

func (p *memPlugin) fold(ctx context.Context, sid string, finalize bool) {
	p.mu.Lock()
	project, model := p.projects[sid], p.models[sid]
	p.mu.Unlock()
	if project == "" {
		return
	}
	o := memory.FoldOptions{
		Session: sessionName(sid), Actor: actorFor(model),
		Transcript: filepath.Join(p.sessionsDir, sid, session.LogFile), Format: "rudy",
		ProjectID: project, Finalize: finalize,
		Summarizer: sdkSummarizer{ctx, p.summarize}, Settings: settingsFrom(p.cfg.Fold), Now: time.Now(),
	}
	due, _, err := memory.FoldDue(p.b, o)
	if err == nil && !due && !finalize {
		return
	}
	st, err := memory.RunFoldJob(p.b, o)
	id, _ := ulid.Parse(sid)
	if err != nil {
		_ = memory.MarkFoldError(p.b, o.Session, err.Error(), time.Now())
		_ = p.host.Note(id, "memory: fold failed: "+err.Error(), session.NoteWarn)
		return
	}
	if st.Status == "skipped" {
		return
	}
	_ = p.host.Note(id, fmt.Sprintf("memory: folded %d observations", st.Observations), session.NoteMuted)
}
```

```go
	cfg     ServerConfig
	session *sdk.ClientSession   // sdk is "github.com/modelcontextprotocol/go-sdk/mcp"

func connect(ctx context.Context, cfg ServerConfig, resolve func(string) (string, error), version string) (*server, error) {
	client := sdk.NewClient(&sdk.Implementation{Name: "rudy", Version: version}, nil)
	var t sdk.Transport
	switch cfg.Transport {
	case TransportStdio:
		cmd := exec.Command(cfg.Command, cfg.Args...)
		cmd.Env = os.Environ()
		for k, ref := range cfg.Env {
			v, err := resolve(ref)
			if err != nil {
				return nil, fmt.Errorf("env %s: %w", k, err)
			}
			cmd.Env = append(cmd.Env, k+"="+v)
		}
		cmd.Stderr = io.Discard // captured to a tail in Task 12's style; here discarded, the notice carries the connect error
		t = &sdk.CommandTransport{Command: cmd}
	case TransportHTTP:
		hc := &http.Client{Transport: &headerTransport{base: http.DefaultTransport, headers: resolvedHeaders}}
		t = &sdk.StreamableClientTransport{Endpoint: cfg.URL, HTTPClient: hc}
	}
	cs, err := client.Connect(ctx, t, nil)
	if err != nil {
		return nil, err
	}
	res, err := cs.ListTools(ctx, nil)
	if err != nil {
		_ = cs.Close()
		return nil, err
	}
	return &server{cfg: cfg, session: cs, tools: res.Tools}, nil
}

func (s *server) call(ctx context.Context, name string, input json.RawMessage) (tool.Result, error) {
	res, err := s.session.CallTool(ctx, &sdk.CallToolParams{Name: name, Arguments: input})
	if err != nil {
		return tool.Result{}, err
	}
	var blocks []session.Block
	for _, c := range res.Content {
		switch v := c.(type) {
		case *sdk.TextContent:
			blocks = append(blocks, session.TextBlock(v.Text))
		case *sdk.ImageContent:
			blocks = append(blocks, session.TextBlock(fmt.Sprintf("[image %s, %d bytes]", v.MIMEType, len(v.Data))))
		default:
			blocks = append(blocks, session.TextBlock(fmt.Sprintf("[unsupported content %T]", c)))
		}
	}
	if len(blocks) == 0 {
		blocks = []session.Block{session.TextBlock("")}
	}
	return tool.Result{Content: blocks, IsError: res.IsError}, nil
}
```

```go
// Peer splits one Conn into our outgoing requests (Client) and their incoming requests
// and notifications (Incoming). One reader goroutine routes each message by shape: a
// response (id, no method) goes to Client's pending call; anything with a method goes to
// the Incoming queue. Incoming.Send writes responses and notifications back on the same Conn.
type Peer struct { ... }
func NewPeer(c Conn) *Peer
func (p *Peer) Client() *Client
func (p *Peer) Incoming() Conn
func (p *Peer) Close() error
```

`Client` today owns its reader; give it an internal constructor `newClientOn(send func(ctx, any) error, responses <-chan Response, done <-chan struct{})` so Peer feeds it, and keep `NewClient(conn)` as the composition of a reader goroutine plus that constructor (refactor, existing tests must stay green).
